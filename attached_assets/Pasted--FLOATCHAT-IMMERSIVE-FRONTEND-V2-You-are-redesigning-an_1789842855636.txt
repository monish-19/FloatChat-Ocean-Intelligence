# FLOATCHAT — IMMERSIVE FRONTEND V2

You are redesigning and significantly upgrading the existing FloatChat frontend.

IMPORTANT:

Do NOT replace the existing design with a generic AI-generated website.

Do NOT rebuild the site as a conventional SaaS dashboard.

Do NOT throw away the current visual identity.

The existing FloatChat site already has a strong visual foundation:

* dark deep-ocean aesthetic
* cyan/teal accents
* editorial typography
* scientific HUD elements
* ARGO float visualization
* depth-based storytelling
* "The ocean is the interface"
* "Scroll is a descent"
* scientific data presentation
* minimal navigation

KEEP THESE CORE IDEAS.

The goal is to evolve the existing site from:

"polished interactive presentation"

into:

"immersive cinematic scientific data experience."

The final result should feel like a creative technology studio built it using WebGL, Three.js and advanced motion design.

Use the visual quality and interaction philosophy of high-end experimental websites such as Emotion Agency as inspiration.

Reference:

https://emotion-agency.com/

DO NOT copy its branding, layout, content or assets.

Borrow the principles:

* immersive 3D
* cinematic transitions
* scroll-driven storytelling
* experimental typography
* strong motion design
* interactive environments
* mouse-driven interaction
* spatial composition
* seamless scene transitions

FloatChat must remain visually original.
